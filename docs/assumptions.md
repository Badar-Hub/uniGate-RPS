# UniGate — Assumptions & Open Questions

**Status:** Phase 1 — living document, updated as answers arrive
**Last updated:** 2026-09-14

The RFP is a two-page commercial document. It defines the *what* at a high level and almost none of the business rules needed to build a working transaction platform. Rather than stall, the design makes explicit, configurable assumptions and records them here.

**Two rules govern this document:**

1. **No assumption is hard-coded.** Every value below is a `system_settings` row, a `commission_rules` row, or an environment variable. Changing an answer is a configuration change, not a code change — unless explicitly marked otherwise.
2. **No assumption is presented to UniGate as a requirement.** Anything below marked `ASSUMED` was chosen by the delivery team and needs confirmation.

Legend — **Impact if wrong:** `LOW` config change · `MEDIUM` code change in one module · `HIGH` schema or cross-module change.
